# TFT Synergy Checker

Teamfight Tactics（TFT）の構成を考える際に、指定したシナジーとコスト上限から対象となるチャンピオンを抽出し、同時に成立するシナジーを確認するために制作したプログラムです。

## 制作について

- 制作区分：個人制作
- 制作期間：2025年4月/2週間
- 使用言語：C、HTML
- 使用環境：Linux、Apache2、CGI
- 主なソースコード：
  - `tft_synagy/source/main.c`
  - `tft_synagy/source/func.h`
  - `tft_synagy/source/tft_synergy.html`

この作品は、制作当時の自分のプログラミング力や試行錯誤が分かるよう、就職活動向けにソースコードそのものを大きく書き直したりリファクタリングしたりせず、当時の実装を基本的に残しています。

## 制作目的

TFTでは、あるシナジーを軸に構成を考える際に、

- そのシナジーを持つチャンピオンは誰か
- 指定したコスト以下では誰が候補になるか
- 候補を集めた場合に、ほかにどのシナジーが成立するか

を何度も確認する必要があります。

そこで、シナジーとコスト上限を入力すると、候補となるチャンピオンと成立するシナジーをまとめて確認できるようにしました。

## 主な処理

1. HTMLフォームからシナジーとコスト上限を入力
2. CGIとして動作するCプログラムでPOSTデータを受信
3. CSVからチャンピオン、コスト、シナジー情報を読み込み
4. 条件に合うチャンピオンを抽出
5. 対象チャンピオンが持つシナジーを集計
6. 結果をHTMLとして出力

## 実行環境・実行方法

制作時はApache2のCGI機能を利用しました。

Apache2をインストールします。

```bash
sudo apt update
sudo apt install apache2
sudo a2enmod cgi
sudo systemctl restart apache2
```

Cプログラムをコンパイルします。

```bash
gcc -o main.cgi main.c
```

制作時はCGI実行ファイルを `/usr/lib/cgi-bin/`、HTMLをApacheの公開ディレクトリに配置して動作させていました。

実行権限がない場合は、例えば次のように付与します。

```bash
chmod 755 /usr/lib/cgi-bin/main.cgi
```

※制作時のディレクトリ構成・Apache設定に依存する部分があります。ソースコードの内容と作品概要は `source/` および `summary.pdf` から確認できます。
